# Working Documents

This folder contains **temporary working documents** created during debugging and development sessions.

## Purpose

- Active debugging notes
- Implementation progress tracking
- Session-specific context
- Temporary analysis documents

## Lifecycle

Documents here are:
- ✅ **Created** during active work
- ✅ **Referenced** during the same session
- ⚠️ **Archived or deleted** once the work is complete
- ⚠️ **Moved to permanent docs** if they contain valuable long-term information

## When to Archive

After completing a debugging session or feature:
1. Extract key insights → Move to appropriate permanent doc
2. Delete temporary notes that are no longer relevant
3. Keep only documents needed for ongoing work

## Permanent Documentation

For long-term reference, use:
- `docs/architecture/` - System design and patterns
- `docs/design-principles/` - Core principles and guidelines
- `docs/troubleshooting/` - **Permanent** troubleshooting guides (not session notes)
- `docs/deployment/` - Deployment procedures and status
